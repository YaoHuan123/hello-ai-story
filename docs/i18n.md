# 界面语言（i18n）规划

本文说明 **Web 先行** 下的中英文分工、配置方式，以及 canonical 英文内部存储 + 展示层翻译的架构。**不含原生 App 构建变体**（见文末「原生后续」）。

## 核心架构（当前约定）

```
用户展示语言（displayLocale）     ← API 边界翻译，仅影响 HTTP 响应 / 前端可见文案
        ↑
meta.locale / APP_LOCALE（zh | en）

内部 canonical（始终英文）        ← LLM I/O、落盘、模板 field key、prompt 全文
```

| 层级 | 语言 | 说明 |
|------|------|------|
| **壳层 UI** | `APP_LOCALE` | 按钮、Tab、错误码等：`frontend/src/i18n/locales/{zh,en}.ts` |
| **业务 canonical** | 英文 | 问句生成、选题 reason、sections 节名（catalog）、视频/文本管线 LLM |
| **中文展示** | `meta.locale === zh` | 目录映射 + 按需 MT（采访级缓存） |

**不存在** `prompts/en/` 双轨；全项目共用一套英文 prompt：`prompts/{interview,preprocess,create-text,create-video,...}/`。

## 语言如何决定（Web）

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | 后端 `APP_LOCALE` | `GET /api/health` → `locale`；整站壳层权威配置 |
| 2 | `VITE_LOCALE` | health 不可用时的构建兜底 |
| 3 | `navigator.language` | 以上皆无时：`zh*` → 中文，否则英文 |

单条采访的业务**展示**语言以 `meta.locale` 为准（创建时写入，与当时 `APP_LOCALE` 一致）。

## 后台开关

`backend/.env`：

```env
APP_LOCALE=zh   # 或 en
```

修改后**重启后端**。前端 Web 刷新即可。

```bash
curl http://localhost:3001/api/health
# "locale": "zh" | "en"
```

## 模板与 catalog

| 文件 | 角色 |
|------|------|
| `frontend/public/template-config.v2.json` | 中文基线（维护源） |
| `frontend/public/template-config.en.overrides.json` | 构建 canonical 时的英文补丁 |
| `frontend/public/template-config.canonical.json` | **运行时 catalog**（英文节名 + field key） |
| `backend/config/display/catalog.zh.json` | **仅展示**：子类名、字段标签、选项、hotTopic 域、**videoStyles**、基本档案问句 |
| `backend/config/video-styles.en.overrides.json` | 视频风格 canonical 英文（管线 + `APP_LOCALE=en` API） |
| `backend/config/display/field-keys.zh-to-canonical.json` | v2 中文字段 key → canonical 映射 |

改 v2 或 overrides 后执行：

```bash
node backend/scripts/build-canonical-catalog.mjs
```

## 提示词

- 路径：`prompts/{子目录}/{文件名}.md`
- 加载：`backend/src/content/promptPath.ts`、`video/shared/llm/loadPrompt.ts` 等
- **无 locale 分支**；修改 prompt 后需重启 backend（内存缓存）

主要子目录：

| 目录 | 用途 |
|------|------|
| `prompts/interview/` | 出题、选题 tier1–3 gating |
| `prompts/preprocess/` | tier5 矛盾检测等 |
| `topic` 模块内联 prompt 文件 | tier2–8（`topic-pick-tier2.md`、`gap-audit.md` 等，位于 `prompts/interview/`） |
| `prompts/create-text/` | 正式文章 |
| `prompts/create-video/` | 传记视频管线 |
| `prompts/interview-studio/` | 演播室脚本 + 时长对齐改写 |

## 展示翻译实现要点

| 模块 | 路径 |
|------|------|
| 展示语言 | `backend/src/content/displayLocale.ts` |
| 目录映射 | `backend/src/content/displayCatalog.ts` |
| API 边界 | `backend/src/content/translate/display.ts` |
| MT + 缓存 | `backend/src/content/translate/runtime.ts` → 采访目录下 `display-translate-cache.json`（含正式长文） |
| 正式文章展示 | `backend/src/text/textArticleDisplay.ts` → `translateArticleForDisplay` |
| 聊天历史 | `backend/src/services/interviewChatHistory.service.ts` |
| 选题 reason | `InterviewQuestion.optionReasons`（`interviewOrchestrator.service.ts`） |

`APP_LOCALE=en` 时：壳层与 `meta.locale=en` 的采访**直接展示英文 canonical**，一般不调用 MT。

`meta.locale=zh` 时：结构字段走 catalog；英文 LLM 文案走 MT 缓存（首次未命中会调 LLM，**不保证实时性能优化**）。

## 原生后续（非 Web 范围）

Capacitor 包计划用 `VITE_LOCALE` 构建时写入壳层语言，**不**依赖运行时 `APP_LOCALE`。Web 验收通过后再排期。

## 自检清单（Web）

1. `APP_LOCALE=zh`：访谈冷启动 → 基本档案中文问句 → 选题卡片见中文 `optionReasons` → 聊天历史中文
2. `APP_LOCALE=en`：同上链路英文展示
3. 改 `prompts/**/*.md` 后重启 backend，跑一轮选题 / 出题 / 视频 prep 确认无混语
