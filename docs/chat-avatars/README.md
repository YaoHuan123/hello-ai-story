# 聊天形象方案（待筛选）

注册用户在 **访谈聊天**（`InterviewPage`）里展示的头像形象。当前聊天 UI 只有气泡、无头像；本文件夹供产品筛选后再落地。

## 怎么用

1. **浏览器预览（推荐）**：用浏览器打开 [`preview.html`](preview.html)，可筛选系列、标记「保留 / 淘汰 / 待定」；选择会保存在浏览器 localStorage。
2. **看清单**：[`catalog.json`](catalog.json) 为机器可读目录；[`catalog.md`](catalog.md) 为表格摘要。
3. **看单个方案**：[`options/`](options/) 下每个形象一份说明 + [`assets/`](assets/) 下对应 SVG 草图。

## 设计原则

| 原则 | 说明 |
|------|------|
| 与品牌一致 | 靛蓝 `#4f46e5` 为主，暖色点缀；扁平圆角，非 3D |
| 访谈场景 | 传记 / 回忆，避免游戏感、幼态过重 |
| 尺寸 | 聊天内 36×36 px（可 @2x 导出 72 px） |
| 用户 vs AI | 本文档为 **注册用户** 形象；AI 采访员建议固定为「小史」，见 `options/interviewer.md` |

## 聊天中的位置（示意）

```
┌─────────────────────────────────────┐
│  [小史]  AI 问句气泡（左）           │
│                                     │
│              用户答句气泡（右） [头像] │
└─────────────────────────────────────┘
```

## 候选数量

- **小动物** 4 个：猫头鹰、猫、乌龟、狐狸  
- **卡通小人** 4 个：爷爷、奶奶、青年、童年  

筛选完成后，把 `preview.html` 里导出的 JSON 或你在 catalog 里勾选的 `id` 列表发给开发即可接入 `users.avatarId`。
